# CodSoft Internship Projects

This repository showcases the projects developed during my internship at CodSoft. The projects encompass web development tasks, including a calculator application, a movie website, and a personal portfolio.

## Projects Overview

### 1. Calculator Project

A web-based calculator application capable of performing basic arithmetic operations. Built using HTML, CSS, and JavaScript, it offers a user-friendly interface for quick calculations.

### 2. Movie Website

A responsive movie website that displays information about various films. It includes features such as movie listings, details pages, and a clean UI design. Technologies used include HTML, CSS, and JavaScript.

### 3. My Portfolio

A personal portfolio website to showcase my skills, projects, and contact information. Designed with a focus on aesthetics and responsiveness, utilizing HTML, CSS, and JavaScript.
